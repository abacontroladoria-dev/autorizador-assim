Sua missão é criar a interface principal da Central de Atendimento.

IMPORTANTE:

Este módulo NÃO utiliza o layout padrão do Pulsar.

Objetivos:

Criar workspace premium inspirado em:

- Kommo
- Intercom
- WhatsApp Web

Implementar:

/app/(workspace)/central-atendimento

Layout:

- Sem sidebar
- Sem header global
- Full width
- Dark mode padrão

Estrutura:

Coluna 1:

- Lista conversas

Coluna 2:

- Chat

Coluna 3:

- Painel contexto

Criar componentes:

- ConversationList
- ConversationItem
- ChatHeader
- MessageList
- MessageComposer
- ContextPanel

Utilizar:

- Shadcn
- Tailwind
- Lucide

Não implementar:

- IA
- Realtime
- Context widgets

Apenas layout e navegação.

Entregáveis:

- Screens funcionais
- Componentes criados
- Estrutura organizada

Ao final apresentar:

"Ready for review"
